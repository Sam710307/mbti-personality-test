原型使用说明

  1. FR 标注：开启后，页面上各功能元素会显示对应的 PRD 需求编号（如 FR-01），蓝色为 P0 必做项，橙色为 P1 增强项，便于对照 PRD 文档评审。
  2. 一键填满答案：自动随机作答全部 60 题，方便快速体验提交与结果流程，无需手动点击。
  3. 直达结果页：跳过答题直接查看结果预览与详细解读页面，适合快速评审 UI 与文案。
  4. 重置：清除所有答案与状态，回到欢迎页。
  5. 正常使用流程：欢迎页 → 测评（60题） → 结果预览 → 详细解读。提交按钮在全部答完前保持禁用（FR-06）。
